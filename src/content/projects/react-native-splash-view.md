## Why I built it

The transition from native app launch to a ready JavaScript UI should feel intentional. This package makes splash presentation controllable from both the native layer and React Native.

## Quick start

```bash
npm install @leo-showdar/react-native-splash-view
```

Native setup differs across iOS and Android; follow the platform-specific instructions in the README.
